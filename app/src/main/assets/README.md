# JmViewer

安卓原生漫画客户端：搜索、原生阅读、收藏、历史、离线下载与缓存管理，界面跟随系统明暗与主题色。

> 本仓库为调试用私有仓库（`_Beta`），正式版请访问 https://github.com/f1uke76/JmViewer

---

## 界面说明

- **主页**：左上角菜单呼出侧边栏，右下角放大镜展开搜索框；未搜索时显示站点推荐，可在设置中关闭。
- **搜索**：输入关键词或作品编号（如 `1464578`、`JM1464578`）后回车；搜索后标题变为「搜索：关键词」，左上角三横变为叉，点叉即可退出搜索。
- **详情**：展示封面、标题、标签、章节与预览图，可收藏、开始阅读或下载；点击预览图可从对应页开始阅读。
- **阅读**：上下滚动阅读，点击画面中部显示进度条，可拖动跳页；支持切换上下话、下载整话与收藏，右滑返回。
- **历史 / 收藏**：长按进入多选，可全选、全不选或批量删除；支持列表与封面两种展示方式。
- **下载**：后台逐本下载并打包，下载中显示进度与开始 / 暂停，完成后可离线阅读；已缓存的图片会直接复用，不重复消耗流量。
- **我的**：收藏与历史汇总，固定使用封面模式展示。
- **设置**：颜色模式、主题色、漫画显示方式、站点与分流、缓存管理、清除记录、导入与导出、关于软件。
- **更新**：在「关于软件」中可手动检查更新；开启「启动检查更新」后，启动时发现新版本会弹窗提示。

## 已知限制

- 站点结构变化时，部分解析可能暂时失效，需等待版本更新。
- 站点域名变化时，可在「设置 → 站点地址」中修改，无需重装。
- 下载内容保存在应用私有目录，卸载应用会一并删除。
- 本仓库仅供个人学习交流，内容均来自站点。
